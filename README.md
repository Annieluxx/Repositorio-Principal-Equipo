Este repositorio fue creado para realizar la actividad colaborativa de GitHub mediante el uso de ramas y Pull Requests.

## Objetivo

Aplicar un flujo de trabajo colaborativo en GitHub, donde cada integrante del equipo trabaje desde una rama independiente y posteriormente integre sus cambios a la rama principal mediante Pull Requests.

## Integrantes

- Annie
- Sarah
- Ximena
- Angel

## Flujo de trabajo

Cada integrante realizara sus modificaciones desde su propia rama, registrara los cambios mediante commits y creara un Pull Request hacia la rama main para que sus aportaciones sean revisadas antes de integrarse al proyecto.
